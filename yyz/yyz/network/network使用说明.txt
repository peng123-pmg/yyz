================================================================================
                    MetaverseSync Network 模块使用说明
================================================================================

一、模块简介
──────────────────────────────────────────────────────────────────────
MetaverseSync 封装了 MQTT 通信，用于实现 Qt 应用与华清远见元宇宙虚拟仿真
平台之间的双向数据同步。本模块独立于具体项目，可直接拷贝到任何 Qt 项目
中使用。

二、文件清单
──────────────────────────────────────────────────────────────────────
network/
  ├── meraversesync.h          // 头文件
  ├── meraversesync.cpp        // 实现文件
  └── network使用说明.txt       // 本文件


三、集成方式
──────────────────────────────────────────────────────────────────────

3.1 拷贝文件
  将整个 network/ 目录拷贝到目标项目的根目录下。

3.2 修改 .pro 文件
  在项目 .pro 文件中加入：

  SOURCES += \
      network/meraversesync.cpp

  HEADERS += \
      network/meraversesync.h

  确保 QT += mqtt 已启用。

3.3 引入头文件
  #include "network/metaversesync.h"


四、API 速查
──────────────────────────────────────────────────────────────────────

4.1 公开方法

  ┌─────────────────────────────────────────────────────────────────┐
  │ connectToHost(host, port)                                       │
  │   连接 MQTT 服务器。连接成功会自动订阅 AIOTSIM2Device 主题。     │
  │   参数: host  - 服务器地址 (如 "mqtt.yyzlab.com.cn")             │
  │         port  - 端口号 (默认 1883)                               │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ disconnectFromHost()                                            │
  │   断开 MQTT 连接。                                              │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ isConnected() → bool                                            │
  │   返回当前是否已连接。                                          │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ sendControlCmd(device, state)                                   │
  │   发送设备控制指令到虚拟仿真平台（发布到 "sub" 主题）。          │
  │   参数: device - 设备名称 ("lamp"/"fan"/"alarm")                │
  │         state  - true=开/on, false=关/off                       │
  │   示例: sendControlCmd("lamp", true)   // 开灯                  │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ sendSensorData(data)                                            │
  │   上报传感器数据到虚拟仿真平台（发布到 "Device2AIOTSIM" 主题）。 │
  │   参数: data - QJsonObject，字段任意，支持扩展                  │
  │   示例:                                                         │
  │     QJsonObject d;                                              │
  │     d["tem"] = 28.5;                                            │
  │     d["hum"] = 65;                                              │
  │     d["pm25"] = 45;                                             │
  │     sendSensorData(d);                                          │
  └─────────────────────────────────────────────────────────────────┘


4.2 信号

  ┌─────────────────────────────────────────────────────────────────┐
  │ connected()                                                     │
  │   MQTT 连接成功时触发。                                         │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ disconnected()                                                  │
  │   MQTT 断开连接时触发。                                         │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ errorOccurred(error)                                            │
  │   发生错误时触发。参数为错误描述字符串。                         │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ controlCmdReceived(device, state)                               │
  │   收到虚拟仿真平台下发的控制指令时触发（来自 "AIOTSIM2Device"）。│
  │   参数: device - 设备名 ("lamp"/"fan"/"alarm")                  │
  │         state  - 开关状态                                       │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ sensorDataReceived(data)                                        │
  │   收到传感器数据时触发。data 为已解析的 QJsonObject。            │
  └─────────────────────────────────────────────────────────────────┘


五、MQTT 主题说明（内部实现，调用方无需关心）
──────────────────────────────────────────────────────────────────────

  ┌───────────────────┬──────────────┬──────────────────────────────┐
  │ Topic             │ 方向         │ 用途                         │
  ├───────────────────┼──────────────┼──────────────────────────────┤
  │ sub               │ 本地 → 仿真  │ 设备控制指令（灯/风扇/报警） │
  │ Device2AIOTSIM    │ 本地 → 仿真  │ 传感器数据上报               │
  │ AIOTSIM2Device    │ 仿真 → 本地  │ 仿真平台下发的控制指令       │
  └───────────────────┴──────────────┴──────────────────────────────┘


六、完整使用示例
──────────────────────────────────────────────────────────────────────

6.1 最小示例（Controller 中）

  #include "network/metaversesync.h"

  // 初始化
  MetaverseSync *m_sync = new MetaverseSync(this);

  // 连接信号
  connect(m_sync, &MetaverseSync::connected, this, []() {
      qDebug() << "元宇宙同步就绪";
  });
  connect(m_sync, &MetaverseSync::errorOccurred, this, [](const QString &err) {
      qDebug() << "错误:" << err;
  });

  // 接收仿真平台指令 → 驱动硬件
  connect(m_sync, &MetaverseSync::controlCmdReceived, this,
      [](const QString &device, bool state) {
          if (device == "lamp")  hardwareSetLed(state);
          if (device == "fan")   hardwareSetFan(state);
          if (device == "alarm") hardwareSetBuzzer(state);
      });

  // 接收传感器数据 → 更新 UI
  connect(m_sync, &MetaverseSync::sensorDataReceived, this,
      [](const QJsonObject &data) {
          updateSensorDisplay(data);
      });

  // 连接服务器
  m_sync->connectToHost("mqtt.yyzlab.com.cn", 1883);


6.2 硬件传感器上报示例

  // 假设 SensorReader 是一个 QThread 线程，定时读取硬件传感器
  // 并通过信号发射数据

  connect(sensorReader, &SensorReader::dataReady, this,
      [m_sync](const QJsonObject &data) {
          m_sync->sendSensorData(data);
          // 无需关心 data 里有什么字段，MetaverseSync 原样转发
      });


6.3 UI 按钮控制示例

  // 开灯按钮
  connect(ui->btnLampOn, &QPushButton::clicked, this, [m_sync]() {
      m_sync->sendControlCmd("lamp", true);
      hardwareSetLed(true);   // 同时驱动真实硬件
  });

  // 关风扇按钮
  connect(ui->btnFanOff, &QPushButton::clicked, this, [m_sync]() {
      m_sync->sendControlCmd("fan", false);
      hardwareSetFan(false);
  });


七、双向同步逻辑说明
──────────────────────────────────────────────────────────────────────

  场景1: 用户在开发板 UI 开灯
    开发板按钮 → sendControlCmd("lamp", true)
    → "sub" topic → 虚拟仿真 3D 场景灯亮

  场景2: 用户在虚拟仿真中开灯
    → "AIOTSIM2Device" topic → controlCmdReceived("lamp", true)
    → Controller 驱动真实 LED 亮 + 更新 UI 按钮文字

  场景3: 硬件传感器采集数据
    SensorReader 线程采集 → sendSensorData(data)
    → "Device2AIOTSIM" topic → 虚拟仿真显示真实数据


八、扩展传感器类型
──────────────────────────────────────────────────────────────────────

  无需修改 network 代码，直接在上报的 QJsonObject 中加入新字段即可：

  QJsonObject data;
  data["tem"]   = 28.5;   // 温度
  data["hum"]   = 65;     // 湿度
  data["pm25"]  = 45;     // PM2.5（新增）
  data["co2"]   = 400;    // CO2（新增）
  m_sync->sendSensorData(data);

  network 层对字段完全透明，不做任何限制。


九、注意事项
──────────────────────────────────────────────────────────────────────

  1. MetaverseSync 使用 QMqttClient，需要 Qt 版本支持 QtMqtt 模块。
  2. 连接成功后会自动订阅 "AIOTSIM2Device"，无需手动调用 subscribe。
  3. 所有 MQTT 操作都是异步的，通过 Qt 信号/槽机制驱动。
  4. 析构时会自动断开 MQTT 连接。
  5. 日志前缀为 "[MetaverseSync]"，可通过 Qt 调试输出查看运行状态。
